面料工作台 · 60 秒上手

完整手册还在编写中，下面是日常使用的全部流程，看完这一页就能开工。

1. 登录

·在工作台登录页填账号＋密码；新建账号还要填团队口令（找管理员要，不会保存）。
·账号在哪个工作台注册就属于哪条线：在本页注册的账号属于面料线，看不到电动行李箱线的任何客户。

2. 建客户

·买家页 →「＋ 新客户」。建的时候就填 5 项规格（成分 / 克重 / 门幅 / 后整理 / 色号）——规格不齐就报价必错价。

3. 一客一对话框

·点客户进对话框：「记客户」照抄客户原话（英文自动挂中文对照）、「记我发」记录我方说过的话；语音按住说话也行。
·写中文意图 →「✦ 生成回复」：AI 出英文＋中文对照，草稿自动过体检（缺规格 / 缺单位 / 缺币种 / 缺有效期 / 绝对化承诺当场拦下）。
·点「发到 WhatsApp」：打开 WhatsApp 且内容已预填；发完回来点「✓ 已发」，没发点「✕ 没发」。

4. 跟进

·跟进页：新建 / 完成跟进任务。面料按样品生命周期推进（样卡 → 剪样 → lab dip → 测试报告 → 试单），不是催单节奏；B2B 周期以月计，推进到寄样就是实打实的进展。

红线（学徒期）

① AI 产出永远是学徒期草拟，逐句核对后再发，没有自动发送路径。
② 本线业务事实（MOQ / 价格 / 报价有效期 / 让步额度）待终裁，含价格的草稿会被体检拦下——绕过去就是砸单。
③ 本工作台不加载另一条业务线的任何话术、资料与照片；看到别的内容立即报管理员。
④ 阶段只在事实已发生时推进，推进必须写依据；标成交＝人工确认即事实。
